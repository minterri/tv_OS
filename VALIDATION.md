# Проверки Quiet TV 0.4.0

Выполнено 25 октября 2026:

- Java-код скомпилирован JDK 17 в Java 8 bytecode; Android SDK 35.
- Ресурсы и манифест собраны aapt2.
- D8 создал classes.dex, минимальный API 26.
- APK собран и подписан персональным тестовым ключом.
- apksigner verify: подписи v2 и v3 прошли проверку.
- zipalign: выравнивание APK прошло проверку.
- aapt2: пакет local.quiettv.home, версия 0.4.0, minSdk 26, targetSdk 30.
- aapt2 dump permissions: разрешений нет, включая INTERNET.
- Манифест: HOME и LEANBACK_LAUNCHER; touchscreen не обязателен; нет служб,
  фоновых получателей или резервного копирования данных приложения.
- PowerShell 7.4.6 в Linux с имитацией adb: диагностика одного устройства,
  успешная установка, отсутствие устройств, несколько устройств,
  неавторизованное устройство, отказ установки, ошибка запуска.
  Все 7 сценариев прошли; при неоднозначном выборе установка не выполнялась,
  после отказа установки команда запуска не выполнялась.
- Диагностика в тесте использовала только операции чтения.

Не проверено:

- Выполнение версии 0.4 на физическом TUVIO TD43FFBHH11 или Android-эмуляторе. Версия 0.1 была запущена пользователем; получено фото интерфейса.
- Внешний вид, навигация пультом и фактическое поведение HOME на прошивке TUVIO.
- Скорость, энергопотребление, восстановление после сна, совместимость стороннего VPN.
- Исполнение PowerShell именно под Windows PowerShell 5.1
  (использован совместимый синтаксис, тестовый запуск — PowerShell 7.4.6/Linux).
- Импорт и Gradle-сборка в Android Studio; готовый APK собран scripts/build.py.

Первый тест на ТВ:

1. Установить и открыть APK, не меняя главную оболочку.
2. Проверить стрелки/OK, удержание OK, избранное и возврат из приложения.
3. Назначить VPN и проверить, что кнопка открывает именно его.
4. Проверить доступ к штатным настройкам.
5. Попробовать штатный выбор HOME. Проверить кнопку «Домой», сон и перезагрузку.
6. Если HOME не меняется, собрать диагностический отчёт; не удалять штатные пакеты.

Эта версия не отключает системную телеметрию и не перепрошивает устройство.

Для версии 0.4 проверено совпадение сертификата подписи с 0.1 и увеличение versionCode до 4. Ключи сохранённых настроек и идентификатор пакета не изменены.

В 0.3 добавлены панель навигации, локальный поиск и запуск Spotify. Java и XML скомпилированы; интерактивная проверка панели, фокуса и экранной клавиатуры на телевизоре пока не выполнена.

В 0.4 скомпилированы карусель, баннер/иконка в превью, анализ цвета и плавный градиент. Добавлена видимость пакета Google Play без новых разрешений. UI/пульт, баннеры конкретных приложений, производительность градиента и Google Play на реальном ТВ пока не проверены.
