# Quiet TV

Персональная оболочка для Android TV: спокойный главный экран с каруселью приложений, локальным поиском и управлением с пульта. Репозиторий: `minterri/tv_OS`.

Это Android-приложение, устанавливаемое как APK. Целевое устройство проекта — TUVIO TD43FFBHH11 с Android 11.

## Состояние проекта

Документ составлен по исходникам и документации из `QuietTV-0.4.0-kit.zip`. Базовый комплект — **0.4.0**. Текущая тестовая версия в `dev` — **0.5.1-dev**, `versionCode = 6`, пакет — `local.quiettv.home`.

Исходники и файлы выпуска из комплекта перенесены в корень репозитория на ветке `dev`. README дополнен описанием архитектуры и планом из обсуждения проекта; исходный README архива не заменяет этот документ.

## Возможности

- Горизонтальная карусель основных приложений, избранное и полный каталог.
- Превью выбранного приложения из его баннера или иконки.
- Плавная смена тёмного фона на основе цвета иконки.
- Боковая навигация, локальный поиск по названиям приложений.
- Запуск установленных Spotify и выбранного VPN-клиента; компактный значок общего каталога в боковой панели.
- Настройки телевизора, запрос назначения главным экраном, часы и сведения о свободном месте.
- Управление стрелками, OK, удержанием OK и кнопкой «Назад».

VPN-кнопка открывает выбранный клиент; соединение настраивается в самом клиенте. Превью представляет собой изображение приложения. Поиск работает по локальному каталогу запускаемых приложений.

## Архитектура

Приложение состоит из одного модуля `app` и одной `MainActivity`, наследующей системную `android.app.Activity`. Текущая реализация объединяет интерфейс, загрузку приложений, хранение настроек и запуск внешних приложений в одном Java-файле. Отдельных слоёв MVVM, репозиториев данных и DI-контейнера в комплекте нет.

```text
Пульт / пользователь
        ↓
MainActivity → интерфейс Android Views, карусель, поиск, панель
        ├── PackageManager → каталог, иконки и баннеры приложений
        ├── SharedPreferences → избранное и выбор VPN
        ├── Intent / ComponentName → запуск приложений и настроек
        └── RoleManager → запрос роли главного экрана
```

### Интерфейс

Экран создаётся программно стандартными Android Views: контейнерами, кнопками, текстовыми и графическими элементами, диалогами. Фокус и события клавиш обеспечивают навигацию с пульта. Ресурсы XML содержат оформление и анимации; отдельных XML-макетов экранов в комплекте нет.

`renderApps()` и `renderCarousel()` формируют каталог и карусель, `showPreview()` обновляет превью, `extractColor()` определяет цвет иконки. `ValueAnimator` и `ArgbEvaluator` используются для плавных цветовых переходов. Навигацией и поиском управляют `showDrawer()` и `showSearch()`.

### Данные и выполнение

Каталог приложений загружается через `PackageManager`; внутренняя модель `App` объявлена внутри `MainActivity`. Для фоновой работы предусмотрен однопоточный `ExecutorService`, а для работы с главным потоком — `Handler` с `Looper.getMainLooper()`. Каталог обновляется при возвращении в оболочку.

Настройки хранятся локально в `SharedPreferences` с именем `quiet-tv`:

| Ключ | Назначение |
| --- | --- |
| `favorites` | Множество закреплённых приложений |
| `vpn` | Компонент выбранного VPN-приложения |
| `home-configured` | Признак собственного списка, в том числе намеренно пустого |

История поиска не сохраняется. Базы данных и серверной части в комплекте нет.

### Интеграция с Android

Манифест объявляет категории `HOME`, `DEFAULT`, `LEANBACK_LAUNCHER` и `LAUNCHER`. Activity работает в альбомной ориентации с `launchMode="singleTask"`. Сенсорный экран не обязателен. Назначение оболочки на кнопку «Домой» зависит от прошивки и системного выбора HOME.

Манифест не запрашивает разрешений, в том числе `INTERNET`; резервное копирование отключено. В комплекте нет служб, получателей автозапуска, аналитики или рекламных SDK. Это относится к Quiet TV, а не ко всем приложениям и прошивке телевизора.

## Технологии и библиотеки

**Сторонних библиотек времени выполнения нет.** Приложение использует системный Android SDK и стандартную библиотеку Java.

| Компонент | Использование |
| --- | --- |
| Java, совместимость Java 8 | Код приложения |
| Android Views, Dialog / AlertDialog | Интерфейс и диалоги |
| PackageManager, Intent, ComponentName | Поиск и запуск приложений |
| SharedPreferences | Локальные настройки |
| Bitmap, Canvas, Drawable, GradientDrawable | Иконки, превью и фон |
| ValueAnimator, ArgbEvaluator | Анимация цвета |
| Handler / Looper, ExecutorService | Главный поток и фоновая работа |
| RoleManager, Settings | Системный выбор HOME и настройки |
| Android Gradle Plugin 8.7.3 | Конфигурация стандартной Android-сборки |
| Python 3, стандартная библиотека | Альтернативный сценарий сборки |
| PowerShell и Android Platform-Tools / ADB | Установка и диагностика ТВ |

Параметры Android: `compileSdk 35`, `minSdk 26` (Android 8.0), `targetSdk 30`. Для сборки комплектом указаны JDK 17, Android SDK Platform 35 и Build-Tools 35.0.0. Gradle Wrapper в архив не включён.

## Сборка

Установите JDK 17, Python 3, Android SDK Platform 35 и Build-Tools 35.0.0. Из корня проекта выполните:

```powershell
python .\scripts\build.py --sdk C:\Android\Sdk
```

Сценарий последовательно запускает `aapt2`, `javac`, D8, `zipalign` и `apksigner`; результат — `QuietTV-0.5.1-dev.apk` в корне проекта. При установленном SDK этот путь сборки не требует загрузки зависимостей из сети. Сценарий пересоздаёт рабочий каталог `build/`.

Проект также содержит конфигурацию для импорта в Android Studio. По отчёту комплекта Gradle-сборка не проверялась. Для обновления уже установленного APK нужно использовать прежний ключ подписи; стандартная debug-подпись Android Studio может отличаться.

## Установка и проверка

APK можно установить на ТВ через файловый менеджер либо через подготовленное и авторизованное ADB-подключение:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Install-TV.ps1 -AdbPath C:\platform-tools\adb.exe
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Diagnose-TV.ps1 -AdbPath C:\platform-tools\adb.exe
```

При нескольких устройствах используйте параметр `-Device` с идентификатором нужного ТВ. Установочный сценарий устанавливает и запускает приложение. Диагностический сценарий собирает сведения о системе и пакетах в отдельную папку.

Согласно `VALIDATION.md` из архива, для 0.4.0 проверены компиляция Java/XML, создание DEX, подпись, выравнивание APK и семь сценариев PowerShell с имитацией ADB. Эти проверки приведены из отчёта комплекта и при создании README заново не выполнялись.

Версия 0.4.0 ещё требует проверки на физическом ТВ: внешний вид, фокус и управление пультом, поведение HOME, сон, перезагрузка, производительность и запуск внешних приложений. В документации комплекта указано, что пользователь запускал на ТВ версию 0.1.

## Направление дизайна и дальнейшие задачи

В [исходном обсуждении проекта в ChatGPT](https://chatgpt.com/share/6ade6539-91a4-83ed-8723-3d2a40450bd0) после выпуска комплекта 0.4.0 запрошен следующий этап:

- Редизайн с главным экраном PlayStation 5 в качестве визуального референса.
- Плавное перелистывание и переходы при навигации по интерфейсу.

В `dev` реализован первый этап редизайна: компактная верхняя лента иконок, увеличение выбранной плитки, крупный блок названия и превью ниже ленты, плавное перемещение ленты, затухание и появление превью, переход цвета фона и появление содержимого при смене раздела. Быстрые повторные нажатия отменяют предыдущую анимацию прокрутки; устаревшее обновление превью отбрасывается. Используются стандартные Android Views и анимации без новых библиотек и графических материалов PlayStation.

Синтаксис Java проверен парсером. Тестовый APK `QuietTV-0.5.0-dev.apk` собран JDK 17 и Android SDK 35; подписи v2/v3, выравнивание и совпадение сертификата с 0.4.0 проверены. Проверка редизайна на ТВ ещё не выполнена. Необходимо проверить фокус, быстрое перелистывание, возврат из панели/поиска и стороннего приложения, а также масштаб интерфейса на целевом устройстве. Готовый `QuietTV-0.4.0.apk` и его контрольная сумма относятся к исходному выпуску и **не содержат редизайн из `dev`**.

Обсуждение также подтверждает требования версии 0.4: размещение «Все приложения» внизу боковой панели, карусель на главной, превью выбранного приложения и динамический цвет фона. В комплекте превью реализовано статическим баннером или иконкой; кнопка Google Play запускает уже установленный магазин.

## Ветки

- `dev` — текущая разработка и проверка изменений.
- `main` — основная ветка, предназначенная для стабильных версий.

Изменения разрабатываются в `dev`; перенос в `main` выполняется после проверки и решения о выпуске стабильной версии.

## Обновление интерфейса 0.5.1-dev

- Главная ближе к композиции PS5: верхняя лента, крупное название, светлая кнопка «Открыть», мягкий фоновый баннер выбранного приложения и градиент для читаемости.
- Плитка 88 dp увеличивается до 1.18 внутри слота 118 × 132 dp; запас внутри слота и отступы карусели оставляют место для рамки фокуса у краёв.
- Полупрозрачная боковая панель с менее сильным затемнением; отдельная кнопка Google Play удалена. Каталог открывается небольшой кнопкой со значком из четырёх квадратов и описанием для доступности.
- Под превью есть кнопка с минусом «Убрать с главной». Стрелка вниз с плитки переводит фокус на «Открыть», стрелка вверх с кнопок возвращает на выбранную плитку. Удаление меняет только список главной; приложение остаётся в каталоге и на телевизоре. Последнее удаление оставляет главную пустой, без автоматического восстановления подборки.
- Тема QuietTheme оформляет диалоги и кнопки подтверждения внутри Quiet TV. Системные панели Android, клавиатура и экраны настроек прошивки этой темой не изменяются.

APK собран и подписан прежним ключом; подписи v2/v3, выравнивание и метаданные проверены. Внешний вид на физическом телевизоре ещё не проверен.
## Посмотреть интерфейс на компьютере

Откройте `preview/index.html` двойным щелчком в браузере. Установка зависимостей, сборка и подключение телевизора не нужны; превью работает без интернета. Кнопка «На весь экран» разворачивает экран 16:9.

В превью доступны карусель с увеличением плиток, переходы, полупрозрачная панель, поиск, каталог и удаление/закрепление приложений. Управление: стрелки, Enter, Esc и M (меню); мышь — наведение и нажатие, правый клик — действия приложения. Демонстрационный список сохраняется в браузере; «Сбросить демо» возвращает исходные плитки.

Это отдельная браузерная модель версии 0.5.1-dev с демонстрационными приложениями и условными иконками. Она не исполняет Java-код APK, не считывает приложения телевизора и не запускает Android-приложения. Она служит для оценки композиции и сценариев; точные размеры, производительность и управление реальным пультом нужно проверять в APK. При изменениях Android-интерфейса превью нужно обновлять отдельно.
